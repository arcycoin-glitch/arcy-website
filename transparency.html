On-chain observationInspect the specified chain, contract and block or transaction. Interpretation still depends on the method and snapshot time.

Third-party data providerDisplay provider identity, reporting scope and freshness where available. Provider-published does not mean confirmed by a second independent source.

Security and financial guarantees

We do not present a third-party audit, liquidity lock, renounced ownership, guaranteed token burn rate, fixed return or solvency assurance here as independently established. If these facts are not evidenced, treat them as unknown.

5. Verify independently — four steps

Match the network and exact contract. Open the Arc explorer link above and compare the complete address with what the website publishes.

Inspect the relevant source. On a Search report, follow the evidence link for the specific metric. Distinguish chain-derived observations from issuer assertions and third-party summaries.

Inspect the code and history. Review GitHub source and completed CI runs. Passing automated tests indicates tested software behavior, not an independent smart-contract security audit.

Record what remains unverified. Do not infer safety from missing evidence, a logo, a screenshot, a social account, a launch date or a green test badge.
